# MrStoreWebsite

MrStoreWebsite is a responsive e-commerce website built using React.js and integrated with Stripe for product management and checkout.

![Demo Image](image.png)

## Features

- Responsive design, optimized for mobile and desktop browsers.
- Product categories include headphones, Bluetooth speakers, wireless earphones, and smartwatches.
- Seamless add-to-cart functionality.
- Data fetched from Stripe for product listings.

## Installation

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the development server with `npm start`.
4. Start the client file with `npm run dev`.


## Usage

1. Navigate through different product categories.
2. Add items to the cart and proceed to checkout.
3. Explore the responsive design on various devices.

## Technologies Used

- React.js
- Strapi API
- HTML/CSS/JavaScript
